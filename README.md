This project was about visualising the Nitrogen Oxide pollution trends in Mile End and Reading using simple matplotlib code.

I chose Mile End as the University I attend is in Mile End and I chose Reading as this was outside of London. This is so I can talk about the distinctions in pollutions between a heavily populated area and an area that is not as populated.

There are no plans to improve this code as this was a project intended for a University assignment although I do not mind talking about such topics.
